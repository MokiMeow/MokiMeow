I'm a computer science student and product-minded developer from India. A lot of my work starts with one question: **when software takes action, can a person understand it, verify it, and stay in control?**

That has led me toward developer infrastructure, governed automation, supply-chain security, and local-first tools. I also enjoy the other end of the spectrum: expressive interfaces, 3D experiments, and visual ways to explain difficult ideas.

### Selected work

| Project | What it does | Built around |
| --- | --- | --- |
| [**OARS**](https://github.com/MokiMeow/OARS) | Governs high-impact actions with policies, approvals, signed receipts, and auditable evidence. | TypeScript / Fastify / Postgres / MCP |
| [**AURORA**](https://github.com/MokiMeow/AURORA) | Runs planning, evaluation, governance, and engineering automation from a local-first orchestrator. | Python / DevOps / GitHub Actions / Observability |
| [**PatchPilot**](https://github.com/MokiMeow/PatchPilot) | Finds dependency vulnerabilities that reach your code, proposes sandboxed fixes, and waits for human approval. | Next.js / OSV / SBOM / Codex |
| [**GEMUI**](https://github.com/MokiMeow/GEMUI) | Generates, compares, visually edits, and exports interface concepts in one design playground. | React / TypeScript / Vite / Gemini |
