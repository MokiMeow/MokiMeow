Agents propose. Code checks. People decide. I like building systems that make each of those steps visible.

## Selected work

- **[Take Two](https://github.com/MokiMeow/take-two)** keeps a film crew on one schedule when the shoot changes. Agents suggest a new plan and the crew approves it after the app checks which scenes are affected. [Watch the two-minute film](https://github.com/MokiMeow/take-two/releases/tag/v1.0)
- **[AxiomGate](https://github.com/MokiMeow/Axiomgate)** sets action limits for Codex and requires verifiable evidence before it can mark a task complete. [Get it on npm](https://www.npmjs.com/package/axiomgate)
- **[PatchPilot](https://github.com/MokiMeow/PatchPilot)** scans dependencies for known vulnerabilities, flags packages your code imports, and keeps remediation behind human approval. [Explore the dashboard](https://trypatchpilot.vercel.app/)

## Open source

I built [Promise Keeper](https://github.com/MokiMeow/promise-keeper) so Hermes users can turn instructions from a chat into enforceable tool rules. It’s in the [Hermes plugin catalog](https://github.com/NousResearch/hermes-agent/pull/151929). I’ve also landed fixes in [ONNX Runtime](https://github.com/microsoft/onnxruntime/pull/33277), [Highway](https://github.com/google/highway/pull/3514), and [React Email](https://github.com/resend/react-email/pull/3795).
